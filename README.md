# MUSE-AI 고등 디지털 물리 탐구실

MUSE-AI는 과학관 AI 교육 교사연구회 이름입니다. 이 사이트는 창의나래관 디지털 물리쇼와 연계한 고등 프로그램의 교실 실습 도구입니다. 전시물의 공식 소프트웨어나 정확한 복제물이 아닙니다.

## 수업 흐름

1. 언덕 높이와 공의 운동을 비교합니다.
2. 웹캠 자세 인식으로 선택한 언덕을 조절합니다.
3. 지형을 바꾸며 골까지 보내는 모둠 전략을 시험합니다.
4. 현장에서 체험하고 웹 실습과 비교합니다.

교실은 차시당 50분 기준입니다. 현장 이동·입장·대기는 별도로 계획합니다.

## 실행

Node.js 22.13 이상과 pnpm을 사용합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm typecheck
pnpm build
```

생성된 `dist`는 정적 사이트입니다. 별도의 서버, 로그인, API 키가 필요하지 않습니다. 배포 경로는 상대 경로이므로 GitHub Pages의 저장소 하위 경로에서도 사용할 수 있습니다. 저장소 Settings → Pages에서 GitHub Actions를 선택하고, 포함된 Pages 워크플로를 해당 브랜치에서 수동 실행하면 배포됩니다. 자동 공개 배포는 하지 않습니다.

## 기능

- Canvas 지형과 공의 운동, 시작·정지·되돌리기
- 드래그, 터치, 키보드 슬라이더로 네 언덕 조절
- 세 가지 지형, 마찰 유무, 속력·높이·에너지 표시
- 웹캠 한 명의 양쪽 어깨 인식 및 담당 언덕 선택
- 차시별 예상·관찰 기록, 최근 30개 순간값, UTF-8 텍스트 다운로드
- 브라우저 로컬 저장, 모바일 레이아웃, 카메라 취소·권한 오류 안내

## 모형과 개인정보

공은 곡선 지형에 구속된 1 kg 점질량입니다. 100 좌표 단위는 1 m, 중력은 9.8 m/s²이며 1/120초 간격으로 수치 적분합니다. 회전, 실제 공의 충돌, 공기 저항은 생략합니다. 지형이 움직이면 외력이 일을 하므로 에너지 보존 비교는 지형 고정·마찰 없음에서 합니다. 수치는 전시물의 실측값이 아닙니다.

MediaPipe가 어깨 좌표를 추정하고 정해진 규칙이 언덕 높이에 연결합니다. AI를 새로 학습시키는 활동은 아닙니다. 모둠은 역할을 번갈아 맡습니다. 동시에 여러 사람을 인식하지 않습니다. 어깨가 불확실하면 지형을 유지합니다.

카메라는 사용자가 버튼을 누를 때만 켭니다. 영상은 전송·녹화하지 않으며 인식은 브라우저 안에서 수행합니다. 카메라를 끄거나 탭을 숨기거나 모드를 바꾸면 트랙을 정지합니다. 최초 모델과 WASM은 Google Storage 및 jsDelivr에서 내려받으므로 학교 네트워크에서 이 도메인 접근과 HTTPS 카메라 권한이 필요합니다. 카메라가 없으면 마우스 실습을 사용합니다.

기록은 해당 브라우저의 localStorage에 저장됩니다. 공용 기기에서는 내려받은 후 사이트 데이터를 지웁니다. 서버로 학생 기록을 모으지 않습니다. 실제 웹캠·조명·학생 거리 조건은 수업 전에 교사가 확인해야 합니다.
